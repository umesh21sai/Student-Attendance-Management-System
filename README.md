# Student Attendance Management System

## Project Overview
This is a Python-based Student Attendance Management System designed to manage student details and track attendance.

## Features
- Add student details using name and roll number.
- Display the list of students.
- Mark attendance as Present or Absent.
- Generate attendance reports.
- Calculate attendance percentage.
- Display a warning when attendance is below 75%.
- Save and load data using JSON.

## Technologies Used
- Python
- JSON

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the Python file using:

   `python your_filename.py`

   Replace `your_filename.py` with your actual Python file name.

## Data Storage
Student information and attendance records are stored in `students.json`.
